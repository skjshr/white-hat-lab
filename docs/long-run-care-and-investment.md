# 長期経営での保守契約と設備の手応え

保守契約の納品不能と、未完了案件を抱えて保守障害を回避できる問題を修正する。設備の効果は購入画面で比較でき、実際に短縮した仕事が進むとオフィスの監視モニターにも反応が出る。

## 保守契約の対象と既存契約の復帰

日次保守は納品時に保存したサービスの仮想環境を点検する。独立した専門案件の操作エンジンはこの対象を持たないため、該当する10種類では標準・特急の単発契約を選ぶ。見積の保守選択時に理由を表示し、APIでも保守付きの新規受注を拒否する。

従来のWeb診断案件では、保守付きで受注すると全検査に合格しても納品に失敗した。その他の専門案件も、専門案件と関係のない基本サービスの仮想環境を保守対象にしていた。新しい対象外表示だけでは、すでに受注済みの保存データを救済できない。

そのため既存契約には「単発契約に変更」を表示する。操作前に維持する料金・納期と取り消す保守予約を説明する。変更しても調査証拠・修正・検査結果・合意した単発料金・納期・現金は維持する。変更内容は契約へ保存する。同じ顧客の実際の保守対象、稼働中の保守契約、別の未完了保守契約は削除しない。保存失敗時は契約変更を巻き戻す。

## 保守対象の変化を未完了案件で止めない

従来は同顧客の通常案件が未完了だと、日を進めても保守対象の障害発生を延期していた。一方で手動点検と保守収入は継続できた。10日間の対照確認では、通常の経路で3回の障害と実修理が必要だったのに対し、別案件を保持した経路では障害・修理とも0回で同額の収入を得られた。

保守対象は通常案件の作業中の仮想環境と独立した保存データであるため、通常案件の有無にかかわらず日次変化の対象にする。進行中の保守障害を重複して作らない保護は維持する。検査が失敗した日は料金を得られず、通常の修復・再点検・顧客満足度の条件で復帰する。通常案件の編集内容や証拠を障害発生時に変更しない。

## 買う前と稼働中に分かる投資効果

- チーム作業デスクの効果に同時受注枠+2を明記する。
- 運用スキルで割引される機材には通常価格と実際の購入価格を表示する。
- 診断コンソールの個別計測−1分と、観葉植物が装飾であることを明記する。
- スキルの次ランクの金額・割合を案件解放の表示で上書きせず、両方を表示する。
- 設置済みの監視モニターは、実際に短縮効果が含まれる同僚の通常作業に反応する。

通常資金からの比較では、監視モニターは注文中には8分の作業を短縮せず、設置後に7分となった。それでも機材画面は待機中のままだった。今回の表示は、実際の作業の進捗・担当・顧客と、当該機材が短縮した時間を参照する。光や動きは作業が進んでいるときだけ出し、停止・接続不可・待機を稼働中に見せない。

機材の寄与は作業開始・予約時に作業時間と一緒に記録する。購入前に予約した仕事、根拠のない古い保存データ、保守点検に後から短縮効果を付けない。予約開始・一時停止・再開・保存再読込でも同じ仕事の記録を維持する。画面再入場・保存再開で開始音を再生し直さない。

## 長期比較の読み方

初期資金5,000円から、見積・受注・実際の設定変更・検証・納品・請求・日次精算・設備購入・保守・雇用のAPIを通る比較を行う。現金・信用・修復結果・時計を直接書き換えて成長させない。待機はゲームの通常の時間進行APIで加速し、使用した時間を記録する。

自動操作は正しい設定をソースから知っている理想実行の上限である。初見の人の調査時間、迷い、失敗率、楽しさを推定する試験ではない。1日1件の比較と共通の営業時間を使う比較を分け、投資で減った操作時間と実際の収入増を混同しない。シミュレーターが解けない案件は未対応として記録し、経営上の行き詰まりと断定しない。

数値を一律に減らす調整は行わず、実際に再現した納品不能と保守回避を先に直す。長期の余剰資金、有限の案件内容、分野の偏り、設備の回収期間は引き続き比較・プレイ観察の対象とする。

## 25日比較の結果

4方針×2種類の仕事量を変更前後で実行した。合計16経路・400日が検証失敗なしで完走し、各経路の保存再開も成功した。通常どおり仕事を完了する8組の経路では、前後の毎日の収支・受注・作業時間・顧客・技能・給与・保守操作が一致した。

| 方針 | 1件/日の最終現金 | 09〜18時に仕事を始める方針の最終現金 | 後者の通常納品数 / 異なる案件数 |
|---|---:|---:|---:|
| 単発・助言優先 | 467,479円 | 447,892円 | 25 / 17 |
| 同じ案件選択・作業設備へ投資 | 447,479円 | 427,892円 | 25 / 17 |
| 保守・社員採用 | 310,810円 | 363,857円 | 35 / 8 |
| 次の案件に応じて技能を分散 | 332,138円 | 591,391円 | 40 / 23 |

営業時間は比較側の方針であり、ゲームが18時に終了する機能ではない。すべての通常納品は期限内で、最後の未収と給与未払いは0。設備投資は同じ契約数で136〜180分を節約したが、この条件では追加の納品収入を生まなかった。保守方針は11〜12件の実際の保守修復と、95〜96回の社員点検を行った。

修正効果は別の同条件対照で確認した。同顧客の別案件を10日間放置する経路では、修正前の障害0件・保守純収入6,500円に対し、修正後は4日目の障害検出から料金が止まり、純収入800円・満足度35・保守停止となった。通常案件を解き、保守対象の実修復・再点検で再開できる経路も検証している。

既知解のシミュレーターが扱えない案件は終盤にも残ったため、「すべて遊び尽くした」「最適戦略を求めた」とは結論づけない。長期の余剰資金と有限カタログの繰り返しは残課題であり、実測値だけを根拠に急な報酬削減や固定費増額を入れていない。
