# White Hat Lab（ホワイトハッカーラボ）

Windows x64を対象とした、オフラインのセキュリティ会社経営シミュレーションゲームです。オフィス内を歩き、自席PCから案件の受注や調査、経営管理を行います。

外部端末への攻撃は行わず、実OSや製品全体を再現したものではないゲーム内模擬環境です。実行時に外部AI、APIキー、クラウドアカウントは必要ありません。

- **バージョン**: 2.2.0
- **エンジン**: Godot Engine 4.7.2
- **開発経緯**: 日本語テキストの作成にGemini Flash、実装・確認にCodexを使用しています。

## ゲーム内容

プレイヤーは小さなセキュリティ会社を運営し、以下の業務サイクルを進めます。

- オフィス内移動と自席PCでの案件受注
- 仮想端末の設定、ログ調査、測定、修正後の検証、納品
- 初回案内および次の作業ガイドに沿った進行
- 備品・設備の購入と社員への業務割当
- 営業日ごとの精算

### 高度案件（9系統）
侵入対応、脅威ハンティング、認可されたペネトレーションテスト、復旧、クラウド同意調査、Web/API認可、マルウェア調査、供給網復旧、検知設計。

請求ポータルでは、[通常の請求業務](docs/living-invoice-service.md)と、操作記録を調べて封じ込め・復旧・再挑戦する[対応演習](docs/incident-response-exercise.md)を利用できます。

機材納入案件では、[準備台](docs/stock-preparation.md)で実シリアルの入荷・接続・検証・発送・顧客受領を確認し、納品と請求確定まで進められます。

[機材導入の受注設計](docs/hardware-intake-plan.md)では、業務資料・導入機器・受入条件を図で確認し、基本料と顧客予算・利益を比較して見積できます。仕入れから復元、機材の納入、入金まで合意した金額と機器番号を引き継ぎます。

[日報の受注と共有復旧](docs/daily-report-work-order.md)では、経理の日報・止まった保存・来客との境界を作業票で確認できます。新しく受注した案件では実際に本日の日報を共有に保存し、来客を通してしまう誤対応を修正して納品・入金へ進みます。

[日報と編集コピーの作業面](docs/document-copy-workflow.md)では、取得した資料を紙として開き、未保存の編集・コピーの保存・実際の共有への転送を区別できます。編集ソフトから戻るとコピーの状態が更新され、保存拒否後も同じ入力で再試行できます。

[ソフト間の往復](docs/taskbar-workflow.md)では、保存や失敗の通知でソフト切り替え位置が動く問題を修正しました。主要ソフトの位置を保ち、多数のソフトを開いた場合もキーボードで切り替えられます。

[サービス監視とソフト間の連携](docs/software-ecosystem-design.md)では、顧客のサービスと実測結果を図で結び、設定変更後の古い測定、再検査、保存した履歴を確認できます。

共有資料の[世代比較](docs/portal-version-comparison.md)では、注文の変更・追加・削除を同じ表で比較し、実ファイルの復元結果を受取側でも確認できます。

支店の再開案件では、[共有元から業務への流れ](docs/business-source-flow.md)を台帳内に表示し、共有停止・資料欠落・読めても利用できないデータを区別できます。

[支店全体の監視](docs/branch-monitoring.md)では、業務端末・共有元・外部共有を設備図で確認し、顧客台帳や注文原本を選んで診断・サービス制御へ移れます。主要操作は画面下に固定しています。

[HTTP診断の観測作業台](docs/diagnostic-workbench.md)では、遮断位置・サーバー応答・取得した注文票・原本の照合を別の造形で調べられます。200応答でも原本が変わっていれば受入条件は不合格のままです。

[共有診断と原本照合](docs/share-diagnostics.md)では、利用者・共有フォルダー・取得したファイル名と、手元の二枚の原本照合を分けて調べられます。一覧取得、内容保全、受入判定を別の状態として確認できます。

[原本検査の現在性](docs/diagnostic-dependencies.md)は、実際に測ったファイルの内容と存在に結び付けています。別の設定変更では検査を残し、対象の変更では以前の証拠として表示します。

[顧客業務の取得対象](docs/business-source-objects.md)は、共有サーバー・CSV原本・受注票などの形で調べられます。読取成功と業務利用の成否を分け、図から前回の取得応答を確認できます。

[納品の成果と精算](docs/receipt-outcome-statement.md)は、評価印、満足度の目盛り、売上から経費を引く紙面で確認できます。対象の紙を選んで保存した検証記録を開けます。

[顧客との次の仕事](docs/customer-continuation-route.md)は、納品物・顧客満足・次の業務を結んだ図から進められます。新支店の受注表を前回の実資料から引き継ぎ、別拠点への退避と復元を確認する継続案件があります。

## 操作方法

- **WASD**: 移動
- **マウス**: 視点移動
- **E**: インタラクト・操作
- **Esc**: メニュー表示

セーブデータの保存先: `%APPDATA%\WhiteHatLab`

## 実行・ビルド手順

### エディタでの起動
1. Godot Engine 4.7.2 をインストールします。
2. プロジェクトマネージャーで `game/project.godot` をインポートして開きます。
3. **F5キー**（プロジェクト実行）で開始します（※F6単体実行ではありません）。

### Windows向けエクスポート
1. Godot 4.7.2用の「Windows Desktop」エクスポートテンプレートを導入します。
2. 「Windows Desktop」プリセットを選択してエクスポートを実行します。
